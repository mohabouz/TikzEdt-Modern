# TikzEdt Modern 0.4.0 Preview — Windows x64

## Downloads

- **Setup-win-x64.exe**: recommended per-user installer; no administrator rights required.
- **Portable-win-x64.zip**: extract the entire archive, then run `TikzEdt.Modern.exe`.
- Both downloads include the .NET 10 Windows Desktop runtime. No separate .NET installation is needed.
- SHA-256 checksums are supplied for both downloads.

## Highlights

- Chemfig visual molecule editor: atoms, groups, rings, nine bond styles, Cram wedges, lone pairs and advisory valence warnings.
- Compact dark toolbar and Photoshop-style atom rail with corner-arrow flyout menus; fixed duplicate element labels.
- Vector previews, pointer-anchored zoom, shared navigation, selection and undo/redo.
- PST-Labo editor: apparatus properties, independent liquid layers and attached straight/elbow/Bezier tubing.
- Transform-aware coordinates, improved source editing, find/replace, multiline shortcuts, LaTeX symbols and color picker.
- PDF/SVG and raster export, improved preview caching and compiler handling.

## Requirements and limitations

Windows 10 version 2004 or newer, or Windows 11, x64-compatible.
Install MiKTeX or TeX Live separately, including packages used by your figures.
`pdftocairo` and `pdfinfo` must be available on PATH; compiler executable paths can be configured in settings.
Chemfig requires `chemfig`; laboratory figures require `pst-labo` and dependencies (LuaLaTeX recommended).
TeX, PDF command-line tools and fonts are not bundled.

This is an unsigned development preview. Windows may display an unknown-publisher or SmartScreen warning.
Visual editing supports the documented Chemfig/PST-Labo subset, not arbitrary TeX macros; consult the repository documentation before round-tripping advanced source.
Chemistry warnings are advisory, not a full chemical validator. Save important documents before trying experimental editing features.

Only the modern application and its required dependencies are included in this repository and these downloads.
