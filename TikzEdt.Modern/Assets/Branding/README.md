# TikzEdt Modern identity

The logo combines TeX typography, a plotted mathematical curve, and a triangular
geometric construction with highlighted vertices, referencing mathematics,
engineering diagrams, and graphical editing.

- `tikzedt-science-logo.png`: original generated artwork.
- `TikzEdt.ico`: packaged Windows icon, with 16, 20, 24, 32, 40, 48, 64, 96,
  128 and 256-pixel frames. Used as the executable icon and application-window icon.
- `tools/Branding/build_icon.py`: reproducible size/format packaging; no artwork edits.

Generation used the **built-in image-generation tool**, not the API/CLI fallback.
Earlier exploratory images were not integrated into the application.

## Final generation prompt

+Use case: logo-brand. Create one finished original Windows app icon for TikzEdt Modern, a TeX and scientific/engineering diagram editor. Fully opaque square image: fill the ENTIRE square canvas edge-to-edge with one completely uniform deep royal-blue color #1246B5. NO transparency, NO rounded corners, NO outside background or padding around the blue square, NO gradients, NO texture, NO noise, NO shadows. In the center, make an elegantly bold white TeX typographic mark, T then slightly lowered E then X, classic serif mathematical typesetting. Integrate one smooth cyan mathematical plot curve sweeping through/around the letters, and a fine light-blue triangular geometric construction with three circular vertices, one tiny warm yellow vertex. Design all these as a single coherent balanced scientific-drawing logo, not a collage. High contrast, thick robust central lettering, restrained simple diagram detail, generous INTERNAL negative space, legible small-size silhouette. Exact text is 'TeX' only. No other text or watermark. Flat crisp vector-like visual. All blue spaces between the letters and geometry must be completely opaque flat solid blue.
