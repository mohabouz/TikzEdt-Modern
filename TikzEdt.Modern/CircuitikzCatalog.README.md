# Circuitikz snippet catalogue

Source: the official CircuiTikZ manual's **The components: list** section:
https://github.com/circuitikz/circuitikz/blob/master/doc/circuitikzmanual.tex

The generated JSON records its source URL, retrieval time, source SHA-256, and
number of parsed declarations. It contains component identifiers, documented
path aliases and corresponding node shapes, with examples generated by TikzEdt.
Connection poles and default diode aliases described elsewhere in the manual
are included explicitly. This is a component catalogue, not every possible
combination of styling keys, package options, pin counts, or user-defined devices.

Manual authors: Massimo Redaelli (2007–2026), Stefan Erhardt (2013–2026),
Stefan Lindner (2015–2026), and Romano Giannetti (2018–2026).
The manual is distributed under the LaTeX Project Public License 1.3c and/or
GNU GPL; the original manual and its explanatory prose are not redistributed
here. Component names are factual identifiers. Snippet examples and short
descriptions are generated by this project.

Regenerate from the official source:

    dotnet run --project tools/CircuitikzCatalog -- TikzEdt.Modern/CircuitikzCatalog.json

Or pass a downloaded `circuitikzmanual.tex` as the second argument for an
offline, version-specific catalogue. No downloaded TeX is executed by the
generator. Newer components require a correspondingly recent Circuitikz
installation. Failed previews are reported and can be retried after updating TeX.
